The sixteen literal role/action/shape cells, seven named faults and two integrity/session sequences must all be present. Role cells alone cannot satisfy the row.

`sharedRoleNativePlan()` fixes each requirement's phase, proof, invocation and definition import. Source role cells and their four ACL faults use the event-capability imports. Synthetic denied-state and renewed-session proofs use the separate nested-PRL import. Their distinct configuration, definition and run identities are retained; candidate artifact, toolkit, Harness producer/source/dependencies, browser and CCD image identities must agree.

The reader reloads the native reports and receipts, validates complete native outcomes and finalization, replays actual event import bindings, verifies the complete sealed candidate artifact, and checks all five shipped toolkit source-map witnesses. Four witnesses match the pinned source exactly. `write-collection-field.component.ts` permits exactly two reviewed hashes:

The retained source-text fixture comes from the pinned Git object and tests this exact disposition.

Denied and revoked responses are retained before consequential assertions as status, byte count, body digest and presence of four fixed synthetic canaries. No raw body, headers or arbitrary error properties enter this projection. Observations bind the exact invocation, candidate, producer source, CCD namespace, definition import and observed version. The role reader rejects missing references and changed bytes; it checks observer case ID, case type, jurisdiction, original canary data and event history. Synthetic personas remain private and are used only for exact actor linkage.

Include all baseline and fault invocations and retain private input, import, observation, lifecycle and cleanup records. Then run from that exact producer checkout:

```sh
node scripts/replay-harness-shared-role.mjs \
  --candidate-artifact /absolute/candidate-artifact.json \
  --ccd-phase /absolute/native-run/ccd \
  --event-phase /absolute/native-run/eventCapability \
  --output /absolute/private/shared-role-binding.json
```
